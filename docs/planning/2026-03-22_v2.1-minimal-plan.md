## Changes

### 1. Convenience Type Alias

**Problem:** `GuardedCommand[Config, NoFlags]` is verbose for simple CLIs.

**Solution:** Add type alias.

```go
// NEW: Convenience alias for CLIs without root-level flags
type SimpleCLI[T any] = GuardedCommand[T, NoFlags]

// Usage:
// Before:
cli, _ := v2.New[Config, v2.NoFlags]("app", "My app", Config{})

// After (same thing, shorter):
cli, _ := v2.NewSimple[Config]("app", "My app", Config{})
```

**Implementation:**
```go
// In guard.go

// SimpleCLI is a convenience alias for GuardedCommand without root-level flags.
// Use this when your CLI only has per-command flags.
type SimpleCLI[T any] = GuardedCommand[T, NoFlags]

// NewSimple creates a CLI without root-level flags.
// This is a convenience wrapper around New[T, NoFlags].
func NewSimple[T any](name, short string, defaults T) (*SimpleCLI[T], error) {
    return New[T, NoFlags](name, short, defaults)
}

// NewSimpleWithLong creates a CLI with long description, without root-level flags.
func NewSimpleWithLong[T any](name, short, long string, defaults T) (*SimpleCLI[T], error) {
    return NewWithLong[T, NoFlags](name, short, long, defaults)
}
```

**Files changed:** 1 (`guard.go`)
**Effort:** 15 minutes

### 2. Rename AddAnyCommand to AddCommandWithFlags

**Solution:** Add method on GuardedCommand, deprecate standalone function.

```go
// NEW: Method version (preferred)
func (g *GuardedCommand[T, F]) AddCommandWithFlags[F2 any](cmd Command[T, F2]) error

// OLD: Still works, but deprecated
// Deprecated: Use cli.AddCommandWithFlags() instead.
```

**Implementation:**
```go

// AddCommandWithFlags adds a command with a different flags type than the root.
// Use this when your command has its own flags struct.
func (g *GuardedCommand[T, F]) AddCommandWithFlags[F2 any](cmd Command[T, F2]) error {
    return addCommandInternal(g, cmd)

// In guard_command.go - update existing AddAnyCommand

// Deprecated: Use GuardedCommand.AddCommandWithFlags() instead.
```

### 3. Make DI Lazy

**Problem:** Scope is always created, even if unused.

**Solution:** Create scope on first access.

```go
// BEFORE: Always created
func (g *GuardedCommand[T, F]) initialize(defaults T) error {
    g.scope = NewScope(g.name)  // Always created
    // ...
}

// AFTER: Lazy creation
func (g *GuardedCommand[T, F]) scopeInstance() *Scope {
    if g.scope == nil {
        g.scope = NewScope(g.name)
    }
    return g.scope
}

func (g *GuardedCommand[T, F]) Scope() do.Injector {
    return g.scopeInstance().Injector()
}

func (g *GuardedCommand[T, F]) ScopeStruct() *Scope {
    return g.scopeInstance()
}
```

**Benefits:**
- No allocation if DI unused
- Transparent to existing users
- Better performance for simple CLIs

**Files changed:** 1 (`guard.go`)
**Effort:** 30 minutes

### 4. Functional Options for New

**Problem:** `NewWithLong` is a separate constructor.

**Solution:** Add functional options pattern.

```go
// NEW: Functional options
type Option[T any, F any] func(*guardedCommandConfig[T, F])

func WithLong[T, F any](long string) Option[T, F] { ... }
func WithVersion[T, F any](version string) Option[T, F] { ... }

// Updated New to accept options
func New[T, F any](name, short string, defaults T, opts ...Option[T, F]) (*GuardedCommand[T, F], error)

// OLD: Still works
func NewWithLong[T, F any](name, short, long string, defaults T) (*GuardedCommand[T, F], error)
```

**Implementation:**
```go
// In guard.go

type guardedCommandConfig[T any, F any] struct {
    long    string
    version string
}

type Option[T any, F any] func(*guardedCommandConfig[T, F])

func WithLong[T, F any](long string) Option[T, F] {
    return func(c *guardedCommandConfig[T, F]) {
        c.long = long
    }
}

func WithVersion[T, F any](version string) Option[T, F] {
    return func(c *guardedCommandConfig[T, F]) {
        c.version = version
    }
}

func New[T, F any](name, short string, defaults T, opts ...Option[T, F]) (*GuardedCommand[T, F], error) {
    cfg := &guardedCommandConfig[T, F]{}
    for _, opt := range opts {
        opt(cfg)
    }

    // Use cfg.long and cfg.version internally
    if cfg.long != "" {
        return NewWithLong(name, short, cfg.long, defaults)
    }
    // ... rest of existing implementation
}

// NewWithLong updated to be a wrapper
func NewWithLong[T, F any](name, short, long string, defaults T) (*GuardedCommand[T, F], error) {
    return New(name, short, defaults, WithLong[T, F](long))
}
```

**Files changed:** 1 (`guard.go`)
**Effort:** 30 minutes

### 6. Add Scope() Convenience Method

**Problem:** Both `Scope()` and `ScopeStruct()` exist, confusing.

**Solution:** Keep both, document preference.

```go
// Scope returns the DI injector for direct samber/do usage.
// For cmdguard Scope methods (Child, Shutdown, etc.), use ScopeStruct().
func (g *GuardedCommand[T, F]) Scope() do.Injector

// ScopeStruct returns the wrapped Scope for cmdguard-specific operations.
// Prefer this over Scope() for better type safety.
func (g *GuardedCommand[T, F]) ScopeStruct() *Scope
```

No code changes, just documentation.

**Files changed:** 1 (`guard.go` comments)
**Effort:** 5 minutes

### 7. Add MustInvoke Helpers

**Problem:** Users write verbose error handling for DI.

**Solution:** Add panic-on-error variants.

```go
// NEW: Panic variants for DI
func MustInvoke[T any](scope *Scope) T {
    v, err := Invoke[T](scope)
    if err != nil {
        panic(fmt.Sprintf("MustInvoke: %v", err))
    }
    return v
}

func MustInvokeNamed[T any](scope *Scope, name string) T {
    v, err := InvokeNamed[T](scope, name)
    if err != nil {
        panic(fmt.Sprintf("MustInvokeNamed: %v", err))
    }
    return v
}
```

**Files changed:** 1 (`scope.go`)
**Effort:** 15 minutes
