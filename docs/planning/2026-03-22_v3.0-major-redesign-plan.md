# cmdguard v3.0 - Major Redesign Plan

**Date:** 2026-03-22
**Version:** v2.0.0 → v3.0.0
**Philosophy:** Clean break, modern API, fix all design issues

---

## Executive Summary

v3.0 is a **complete API redesign**. Breaking changes are acceptable. The goal is the best possible API for the next 5+ years.

| Metric             | Value                   |
| ------------------ | ----------------------- |
| Breaking Changes   | Major                   |
| New API Surface    | Complete redesign       |
| Migration Effort   | Medium (search/replace) |
| Development Effort | 2-3 weeks               |
| Risk               | High (but worth it)     |

---

## Core Philosophy

### Design Goals

1. **Single type parameter** - `CLI[T]` only, flags handled differently
2. **Consistent naming** - `CLI`, not `GuardedCommand`
3. **Functional options everywhere** - No `NewWithLong` variants
4. **DI is optional** - Opt-in, not forced
5. **No `any` in public API** - Type-safe throughout
6. **Composable** - Works with samber/do elegantly

### Non-Goals

- Backward compatibility with v2.x
- Supporting Go < 1.21

## API Design

### Core Types

```go
package v3

// CLI is the main application type.
// T is the configuration type shared across all commands.
type CLI[T any] struct {
    // private fields
}

// Command represents a typed command with its own flags.
// F is the flags type for this specific command.
type Command[T any, F any] struct {
    Use        string
    Short      string
    Long       string
    Aliases    []string
    Example    string
    Flags      F  // Default flag values
    RunE       func(ctx context.Context, cfg *T, flags F) error
    PreRunE    func(ctx context.Context, cfg *T, flags F) error
    PostRunE   func(ctx context.Context, cfg *T, flags F) error
    Commands   []CommandDef  // Can have ANY subcommand type
    Hidden     bool
    Deprecated string
    Version    string
}

// CommandDef is the interface for any command type.
// This allows mixed flag types in subcommands.
type CommandDef interface {
    isCommand()
    validate() error
}

// NoFlags is a sentinel type for commands without flags.
type NoFlags = struct{}
```

### Constructor

```go
// New creates a new CLI application.
func New[T any](name, short string, defaults T, opts ...Option[T]) (*CLI[T], error)

// Option configures the CLI.
type Option[T any] func(*cliConfig[T])

// Available options:
func WithLong[T any](desc string) Option[T]
func WithVersion[T any](v string) Option[T]
func WithDI[T any]() Option[T]
func WithScope[T any](s *Scope) Option[T]
func WithHelpTemplate[T any](tpl string) Option[T]
func WithErrorHandling[T any](f func(error)) Option[T]
func WithCobraConfig[T any](f func(*cobra.Command)) Option[T]
```

### Command Management

```go
// AddCommand adds a command to the CLI.
// The command can have ANY flags type - type safety is preserved.
func (c *CLI[T]) AddCommand(cmd CommandDef) error

// AddCommands adds multiple commands.
func (c *CLI[T]) AddCommands(cmds ...CommandDef) error

// Command creates a new command builder.
func Command[T, F any](use string, opts ...CommandOption[T, F]) *Command[T, F]

// CommandOption configures a command.
type CommandOption[T any, F any] func(*Command[T, F])

// Available options:
func WithShort[T, F any](s string) CommandOption[T, F]
func WithLong[T, F any](s string) CommandOption[T, F]
func WithFlags[T, F any](f F) CommandOption[T, F]
func WithRunE[T, F any](f func(ctx context.Context, cfg *T, flags F) error) CommandOption[T, F]
func WithPreRunE[T, F any](f func(ctx context.Context, cfg *T, flags F) error) CommandOption[T, F]
func WithPostRunE[T, F any](f func(ctx context.Context, cfg *T, flags F) error) CommandOption[T, F]
func WithAliases[T, F any](a ...string) CommandOption[T, F]
func WithExample[T, F any](e string) CommandOption[T, F]
func WithHidden[T, F any](h bool) CommandOption[T, F]
func WithDeprecated[T, F any](msg string) CommandOption[T, F]
func WithSubcommands[T, F any](cmds ...CommandDef) CommandOption[T, F]
```

### Execution

```go
func (c *CLI[T]) Execute(ctx context.Context) error
func (c *CLI[T]) ExecuteWithArgs(ctx context.Context, args []string) error
func (c *CLI[T]) ExecuteAndExit(ctx context.Context)
func (c *CLI[T]) MustExecute(ctx context.Context)  // Panics on error
```

### Accessors

```go
func (c *CLI[T]) Name() string
func (c *CLI[T]) Short() string
func (c *CLI[T]) Long() string
func (c *CLI[T]) Version() string
func (c *CLI[T]) Config() *T
func (c *CLI[T]) SetConfig(cfg T)
func (c *CLI[T]) RootCommand() *cobra.Command
func (c *CLI[T]) Scope() *Scope  // nil if DI not enabled
```

### Lifecycle

```go
func (c *CLI[T]) Shutdown(ctx context.Context) error
func (c *CLI[T]) HealthCheck(ctx context.Context) error
```

### Dependency Injection

```go
// Scope is the DI container (only created if WithDI() used)
type Scope struct {
    // private fields
}

func NewScope(name string) *Scope
func (s *Scope) Child(name string) *Scope
func (s *Scope) Name() string
func (s *Scope) Parent() *Scope
func (s *Scope) Injector() do.Injector
func (s *Scope) Shutdown(ctx context.Context) error
func (s *Scope) HealthCheck(ctx context.Context) error
func (s *Scope) IsRoot() bool
func (s *Scope) Path() []string

// DI helpers (all return error if scope is nil)
func Provide[T any](s *Scope, provider func(do.Injector) (T, error)) error
func ProvideNamed[T any](s *Scope, name string, provider func(do.Injector) (T, error)) error
func ProvideValue[T any](s *Scope, value T) error
func Invoke[T any](s *Scope) (T, error)
func InvokeNamed[T any](s *Scope, name string) (T, error)
func MustInvoke[T any](s *Scope) T
func MustInvokeNamed[T any](s *Scope, name string) T

// Package function for samber/do integration
func Package[T any](name, short string, defaults T, opts ...Option[T]) func(do.Injector)
```

### Flag Registry (Internal)

```go
// FlagRegistry is generic over the flags type.
type FlagRegistry[F any] struct {
    // private fields
}

func newFlagRegistry[F any](cfg *F) (*FlagRegistry[F], error)
func (r *FlagRegistry[F]) registerFlags(cmd *cobra.Command) error
func (r *FlagRegistry[F]) validateFlags(cmd *cobra.Command) error
func (r *FlagRegistry[F]) parseFlags(cmd *cobra.Command, cfg *F) error
```

### Error Types

```go
// Sentinel errors
var (
    ErrInvalidCommand    = errors.New("invalid command definition")
    ErrMissingHandler    = errors.New("command has no handler")
    ErrMissingName       = errors.New("command has no name")
    ErrFlagParseFailed   = errors.New("failed to parse flags")
    ErrConfigValidation  = errors.New("configuration validation failed")
    ErrDuplicateCommand  = errors.New("command already exists")
    ErrInvalidScope      = errors.New("scope is invalid or not enabled")
    ErrServiceNotFound   = errors.New("service not found in DI container")
    ErrServiceConstruct  = errors.New("failed to construct service")
    ErrDINotEnabled      = errors.New("DI not enabled, use WithDI() option")
)

// Typed errors
type CommandError struct { Name string; Err error }
type FlagError struct { Flag string; Err error; Suggestion string }
type ConfigError struct { Field string; Err error }

// Error constructors
func NewCommandError(name string, err error) *CommandError
func NewFlagError(flag string, err error) *FlagError
func NewFlagErrorWithSuggestion(flag, err, suggestion string) *FlagError
func NewConfigError(field string, err error) *ConfigError
```

## Usage Examples

### Basic CLI

```go
package main

import (
    "context"
    "fmt"
    "github.com/larsartmann/cmdguard/v3"
)

type Config struct {
    LogLevel v3.LogLevel `flag:"log-level" short:"l" default:"info" help:"Log level"`
}

func main() {
    cli, err := v3.New[Config]("myapp", "My application", Config{})
    if err != nil {
        panic(err)
    }

    cli.AddCommand(v3.Command[Config, v3.NoFlags]("greet",
        v3.WithShort("Say hello"),
        v3.WithRunE(func(ctx context.Context, cfg *Config, _ v3.NoFlags) error {
            fmt.Println("Hello!")
            return nil
        }),
    ))

    cli.ExecuteAndExit(context.Background())
}
```

### CLI with Flags

```go
type GreetFlags struct {
    Name  string `flag:"name" short:"n" default:"World" help:"Name to greet"`
    Shout bool   `flag:"shout" default:"false" help:"Shout the greeting"`
}

cli.AddCommand(v3.Command[Config, GreetFlags]("greet",
    v3.WithShort("Say hello"),
    v3.WithFlags(GreetFlags{}),
    v3.WithRunE(func(ctx context.Context, cfg *Config, flags GreetFlags) error {
        msg := fmt.Sprintf("Hello, %s!", flags.Name)
        if flags.Shout {
            msg = strings.ToUpper(msg)
        }
        fmt.Println(msg)
        return nil
    }),
))
```

### CLI with DI

```go
type Database struct { /* ... */ }

func NewDatabase(cfg *Config) (*Database, error) {
    return &Database{dsn: cfg.DSN}, nil
}

func main() {
    cli, _ := v3.New[Config]("myapp", "My app", Config{},
        v3.WithDI(),
    )

    // Register services
    v3.Provide(cli.Scope(), func(i do.Injector) (*Database, error) {
        cfg := v3.MustInvoke[*Config](cli.Scope())
        return NewDatabase(cfg)
    })

    cli.AddCommand(v3.Command[Config, v3.NoFlags]("migrate",
        v3.WithRunE(func(ctx context.Context, cfg *Config, _ v3.NoFlags) error {
            db := v3.MustInvoke[*Database](cli.Scope())
            return db.Migrate(ctx)
        }),
    ))

    cli.ExecuteAndExit(context.Background())
}
```

### Mixed Subcommands

```go

```

## Migration Guide (v2 → v3)

### Type Changes

| v2                        | v3                        |
| ------------------------- | ------------------------- |
| `v2.GuardedCommand[T, F]` | `v3.CLI[T]`               |
| `v2.Command[T, F]`        | `v3.Command[T, F]` (same) |
| `v2.NoFlags`              | `v3.NoFlags` (same)       |

### Constructor Changes

| v2                          | v3                                 |
| --------------------------- | ---------------------------------- |
| `v2.New[T, F](...)`         | `v3.New[T](...)`                   |
| `v2.NewWithLong[T, F](...)` | `v3.New[T](..., v3.WithLong(...))` |

### Command Changes

| v2                           | v3                               |
| ---------------------------- | -------------------------------- |
| `cli.AddCommand(cmd)`        | `cli.AddCommand(cmd)` (same)     |
| `v2.AddAnyCommand(cli, cmd)` | `cli.AddCommand(cmd)` (unified!) |
| `cli.AddCommandFunc(fn)`     | `cli.AddCommand(fn())` (removed) |

### DI Changes

| v2                             | v3                                    |
| ------------------------------ | ------------------------------------- |
| `cli.Scope()` (always created) | `cli.Scope()` (nil if DI not enabled) |
| `cli.ScopeStruct()`            | `cli.Scope()` (unified)               |
| `v2.Provide(scope, ...)`       | `v3.Provide(scope, ...)` (same)       |

### Example Migration

```go
// v2 CODE
root, _ := v2.New[Config, v2.NoFlags]("myapp", "My app", Config{})

greetCmd := v2.Command[Config, GreetFlags]{
    Use:   "greet",
    Short: "Say hello",
    RunE: func(ctx context.Context, cfg *Config, flags GreetFlags) error {
        fmt.Printf("Hello, %s!\n", flags.Name)
        return nil
    },
}

v2.AddAnyCommand(root, greetCmd)
root.ExecuteAndExit(ctx)

// v3 CODE
cli, _ := v3.New[Config]("myapp", "My app", Config{})

cli.AddCommand(v3.Command[Config, GreetFlags]("greet",
    v3.WithShort("Say hello"),
    v3.WithFlags(GreetFlags{}),
    v3.WithRunE(func(ctx context.Context, cfg *Config, flags GreetFlags) error {
        fmt.Printf("Hello, %s!\n", flags.Name)
        return nil
    }),
))

cli.ExecuteAndExit(ctx)
```

## Breaking Changes Summary

| Change                            | Impact          | Migration              |
| --------------------------------- | --------------- | ---------------------- |
| Package path                      | All imports     | `v2` → `v3`            |
| `GuardedCommand[T, F]` → `CLI[T]` | Type signatures | Remove `F`             |
| `New[T, F]` → `New[T]`            | Constructors    | Remove `F`             |
| `AddAnyCommand` removed           | Commands        | Use `AddCommand`       |
| `AddCommandFunc` removed          | Commands        | Use `AddCommand(fn())` |
| `ScopeStruct` removed             | DI              | Use `Scope()`          |
| `NewWithLong` removed             | Constructors    | Use `WithLong` option  |
| DI not auto-created               | DI users        | Add `WithDI()` option  |
