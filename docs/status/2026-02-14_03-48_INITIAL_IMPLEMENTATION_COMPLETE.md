## Known Limitations

### Current Limitations

1. **posflag Integration**: The cobra flag provider is implemented but needs more thorough integration testing with actual flag lifecycle
2. **Health Check Efficiency**: Uses individual service checks instead of bulk health check API
3. **No Structured Logging**: Currently uses `fmt.Println`, should migrate to `slog` or similar
4. **No Integration Tests**: Only unit tests exist, need end-to-end tests
5. **No CI/CD**: No GitHub Actions or other automation

### Design Decisions

| Decision | Rationale |
|----------|-----------|
| Used `sync.RWMutex` in Registry | Thread-safe command/flag registration |
| Lazy services (not eager) | samber/do/v2 v2 doesn't have `ProvideEager`, uses lazy by default |
| Separate registry and validator | Single responsibility principle |
| Public API in `pkg/cmdguard` | Follows Go module best practices |
| No global state | All state managed via DI container |
