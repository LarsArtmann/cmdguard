## e) WHAT WE SHOULD IMPROVE

### Process Improvements

1. **Tag after ALL doc updates are committed** — I updated AGENTS.md AFTER creating tags. Should have done doc updates first, verified the commit, THEN tagged. Or re-tagged after the auto-commit.

3. **Pre-tag checklist** — Before creating ANY tag: (a) all doc version refs updated, (b) committed, (c) build/test/lint pass on the exact commit to be tagged, (d) CHANGELOG ordered correctly.
4. **README.md version sweep** — Should be part of the release checklist. I only checked AGENTS.md.
5. **flightrecorder test flakiness** — Observed a test failure during final verification, dismissed as "pre-existing".
