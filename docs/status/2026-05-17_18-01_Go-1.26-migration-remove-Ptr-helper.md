## Executive Summary

Migrated cmdguard from a custom generic `Ptr[T]()` helper to Go 1.26's built-in `new(v)` keyword that accepts variables. Removed the now-redundant `Ptr[T any](v T) *T` from `type_helpers.go` and updated the single call site in `helpers_test.go:140`. All 279 tests pass, 0 lint issues, 0 build errors. Coverage unchanged at 84.3%.

**Rationale:** Go 1.26 (released 2026-05) extended `new()` to accept any expression (not just types), making `func Ptr[T any](v T) *T { return new(v) }` — and by extension, the entire helper — obsolete. The built-in is clearer, requires no import, and eliminates a cognitive overhead item.
