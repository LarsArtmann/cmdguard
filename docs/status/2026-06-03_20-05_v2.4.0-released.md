## e) WHAT WE SHOULD IMPROVE

1. **`configload` at 0% coverage** — YAML/TOML/Auto loaders have no tests. ~30 min of smoke tests.

2. **Pre-commit hooks broken** — `go-structure-linter` fails on every commit. Workaround: `git commit --no-verify`. Fix: remove or update the hook.

3. **Benchmarks not in CI** — 22 benchmarks exist but aren't automated. Performance regressions go undetected.

4. **flake.nix could add build checks** — Now that go-output is published, `flake.nix` could add `buildGoModule` or `go vet`. Currently only devShell + formatter + format check.

5. **`NoFlags` type alias** — `type NoFlags = struct{}` allows `var f NoFlags = nil`. Distinct type would prevent this. Breaking change, deferred to v3.0.

6. **Example coverage** — `examples/taskctl` at 71.1% — could be higher but acceptable for an example.
