How cmdguard Integrates with fang

Integration point: cli.go — fang.Execute(flowCtx, cli.rootCmd, cli.fangOpts...)

Control: WithFang(true/false) enables/disables; WithFangOptions(opts...) passes through raw fang options

Version/Commit: WithCLIVersion auto-appends fang.WithVersion; WithCLICommit auto-appends fang.WithCommit — single option controls both cmdguard and fang

NO_COLOR: applyNoColorIfSet() sets NO_COLOR=1 before fang execution when --no-color flag is set; fang's colorprofile picks it up automatically

Recommendations

MEDIUM — Expose WithErrorHandler

Add WithFangErrorHandler[T](fn) CLI option so users can customize error formatting. Currently errors always use fang's default styled output. Power users may want structured error output or custom branding.

Effort: ~15 lines in cli_options.go, just appends to cli.fangOpts.

LOW — Expose WithColorSchemeFunc

Allow custom color themes. Niche — most CLIs are fine with fang defaults. Could be exposed as WithFangColorScheme[T](fn).

How cmdguard Uses go-output

Integration file: output.go — re-exports format constants, provides OutputResult, OutputTable, OutputStyledTable

Rendering architecture: Two registries — tableFormatRegistry (12 renderers for *TableData) and anyFormatRegistry (2 renderers for arbitrary data: JSON + YAML)

CLI flag: --output / -o registered via cli_output.go, parsed via ParseOutputFormat

Sub-packages used: d2, delimited, graph, markup, serialization, table

Missing Formats — Details

JSONL (JSON Lines)

go-output provides: JSONLTableRenderer and streaming JSONLWriter. Useful for streaming/piped output.

cmdguard gap: Not in format constants or registries. High value — JSONL is standard for log processing pipelines.

Effort: Add constant re-export + table renderer entry. ~5 lines.

AsciiDoc

go-output provides: AsciiDoc table rendering. Useful for documentation generation.

cmdguard gap: Not exposed. Medium value — nice for CLI tools that generate docs.

TOML

go-output provides: Full support (Table, Tree, Graph). Uses go-toml/v2.

cmdguard gap: Not exposed. Medium value — TOML is common in config-heavy CLIs.

PlantUML

go-output provides: Component diagrams via PlantUMLDiagram. Table, Tree, and Graph shapes.

cmdguard gap: Not exposed. Low value — niche format for architecture visualization.

Recommendations

HIGH — Add JSONL support

JSONL is the de facto standard for streaming structured data. Many CLI tools output JSONL for pipe compatibility. Missing this format limits cmdguard's utility in data pipeline contexts.

Effort: Add FormatJSONL constant re-export + table registry entry using serialization or go-output/enum. ~8 lines total.

MEDIUM — Add TOML support

TOML is widely used in Go config files. Exposing it makes cmdguard a one-stop output solution. go-output already handles all shapes.

LOW — Add AsciiDoc and PlantUML

Niche formats. Add when users request them, or when go-output adds more capabilities. Low urgency.
