03Type Safety Audit

No interface{} / any escape hatches in domain code

The only any uses are: (a) BranchingFlowContext.values map[any]any — a deliberate bag for user-typed values, with typed accessors Value[T](); (b) TypeHandler.Parse returning (any, error) — unavoidable because the parsed value's type depends on reflect.Type at runtime; (c) commandSpec storing hooks as lifecycleHook (sealed interface with unexported method) — type-safe via the generic constructors. No raw interface{} in domain entities.

Branded types enforce invariants at construction

Email, Port, URL, FilePath, HostPort, Duration, Enum, AuditLogFormat — every one has a Parse* constructor that validates. Zero-value is “unset” and IsEmpty() / IsValid() distinguishes. See data-model-review report for the full table.

Errors are structured + sentinel-chainable

58 sentinels in errors*.go, all errors.Is-chainable via fmt.Errorf("%w: ...", sentinel). Custom error types (EnumError, CommandError, ConfigError) support errors.AsType[T] (Go 1.26). No string-matching error handling anywhere.

04Split Brains

None detected.

No competing concepts under different names (the StringSliceContains / ContainsString pair in testutil is the closest, and it is a duplicate function, not a duplicate concept). Domain language is consistent: Scope everywhere (not Container / Injector), FlagRegistry everywhere (not FlagSet / FlagStore), Command everywhere (not Cmd / Action).

05Strengths (preserve these)

+
Zero panics by design, not by luck Every constructor returns error. safeProvide wraps user providers with recover(). AssertPanics exists only in testutil for verifying the invariant.
+
Sealed interface pattern for type-safe hooks lifecycleHook, configValidator, middlewareList, postFlagParseList, cleanupHookList, subcommandList — all use unexported method tags so only cmdguard can construct them. Generic type info is preserved without genericizing the option type.
+
Consistent error wrapping discipline Every fmt.Errorf uses %w with a sentinel. errors.Join aggregates without losing individuals. wrapIfError helper is nil-safe.
+
Copy-on-write registries FlagRegistry + typeRegistry + validatorRegistry all share global maps lazily and clone on first write. Documented in ADR-003.
+
Zero-allocation iterators TagsSeq, FlagNamesSeq, PathSeq, ChildrenSeq return iter.Seq[T] (Go 1.23+). Slice-returning variants return defensive copies. Both patterns coexist deliberately.
+
Documented //nolint with rationale Every //nolint:dupl, //nolint:gochecknoglobals, //nolint:exhaustive carries a one-line reason. No bare silencing.
