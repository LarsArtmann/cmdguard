At threshold 5 (duplicated statements), 1 clone group remains. At threshold 3, 5 clone groups. All reviewed below with judgment per clone.

Accept

Clone 1: validateMin / validateMax (flags_validate.go:253-296)

pkg/cmdguard/v3/flags_validate.go:253-266 and :276-289

Two ~14-line validators with the same shape: parse name:value, convert to float64, compare against actual, return wrapped sentinel. The only differences are the operator (< vs >) and the sentinel (ErrValueTooSmall vs ErrValueTooLarge).

Why we accept Forcing a single generic helper would either take a comparator function argument (more params than the duplicated code has lines) or use a numeric operator token (stringly-typed dispatch). The current pair reads more clearly than validateRange(val, opLess, ErrValueTooSmall) would. Two near-copies that name their intent are preferable to one abstraction that hides it.
Accept

Clone 2: validateMinLen / validateMaxLen (flags_validate.go:217-243)

pkg/cmdguard/v3/flags_validate.go:217-225 and :235-243

Same pattern as Clone 1, but for string length validation. Acceptable for the same reason: the abstraction cost exceeds the duplication cost.

Accept

Clone 3: validator loop in flags_validate.go:71-77 and type_handler.go:114-120

pkg/cmdguard/v3/flags_validate.go:71-77 · type_handler.go:114-120

Both iterate over registered validators and short-circuit on first error. Different domains (flag validators vs type handlers) make extraction artificial; both are 7 lines and read fine inline.

Accept

Clone 4: FilePath validators (types_filepath.go:91-112)

pkg/cmdguard/v3/types_filepath.go:91-98 and :105-112

validateFile and validateDir share structure (call os.Stat, check mode bit). The two differ in IsRegular() vs IsDir(), which is the entire point of having two functions. Acceptable.

Review

Clone 5: FlowContext.Shutdown vs Scope.Shutdown (6 lines)

pkg/cmdguard/v3/flow_context.go:175-180 · scope.go:82-87

Both walk a list of shutdown hooks/services in reverse order and collect errors via errors.Join. Worth a glance — could potentially share a small shutdownAllReverse[T] helper — but the type signatures differ enough ([]ShutdownHook vs []do.ShutdownHook) that the abstraction earns little. Acceptable as-is; flag for revisit if either grows.
