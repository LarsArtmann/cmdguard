### 3. Added Custom Types
**Status:** ✅ Implemented

Created `types_custom.go` with 5 new validated types:

1. **URL** - Validated URL with scheme/host requirements
   - `ParseURL(s string) (URL, error)`
   - `MustParseURL(s string) URL`
   - Methods: `URL()`, `String()`, `IsEmpty()`, `Scheme()`, `Host()`, `Hostname()`, `Port()`, `Path()`
   - Text marshaling support

2. **Email** - Validated email address
   - `ParseEmail(s string) (Email, error)`
   - `MustParseEmail(s string) Email`
   - Methods: `String()`, `Address()`, `IsEmpty()`, `Local()`, `Domain()`
   - Text marshaling support

3. **Port** - Validated port number (1-65535)
   - `ParsePort(s string) (Port, error)` - Supports named ports (http, https, ssh, ftp, dns, smtp)
   - `MustParsePort(s string) Port`
   - `PortFromInt(port int) (Port, error)`
   - Methods: `Int()`, `String()`, `IsValid()`, `IsWellKnown()`, `IsRegistered()`, `IsDynamic()`
   - Text marshaling support

4. **FilePath** - Validated file system path
   - `ParseFilePath(s string, checkExists bool) (FilePath, error)`
   - `MustParseFilePath(s string, checkExists bool) FilePath`
   - Methods: `String()`, `Absolute()`, `Exists()`, `IsEmpty()`, `IsDir()`, `IsFile()`, `Dir()`, `Base()`, `Ext()`, `Join()`
   - Text marshaling support

5. **HostPort** - Combined hostname and port
   - `ParseHostPort(s string) (HostPort, error)`
   - `MustParseHostPort(s string) HostPort`
   - `NewHostPort(host, portStr string) (HostPort, error)`
   - Methods: `String()`, `Host()`, `Port()`, `IsEmpty()`, `IsAnyHost()`
   - Text marshaling support
