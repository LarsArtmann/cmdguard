## Cobra

[Cobra](https://github.com/spf13/cobra) is the underlying CLI framework that cmdguard wraps. cmdguard adds type safety, DI, and eliminates footguns while keeping full Cobra compatibility.

## samber/do

[samber/do](https://github.com/samber/do) provides the dependency injection runtime. cmdguard integrates it with lifecycle management, health checks, and graceful shutdown.

## go-output

[go-output](https://github.com/larsartmann/go-output) provides the 16 output formats (table, JSON, CSV, YAML, D2, Mermaid, etc.) that cmdguard exposes via `OutputTable` and `OutputResult`.

## fang

[fang](https://github.com/charmbracelet/fang) provides styled help and error output. cmdguard enables it by default for beautiful terminal rendering.

## huh

[huh](https://github.com/charmbracelet/huh) provides interactive prompts. The `prompts` sub-module wires it into cmdguard's `PromptRunner` interface for `WithPromptOnMissing` functionality.

## samber-do-auditlog

[samber-do-auditlog](https://github.com/larsartmann/samber-do-auditlog) traces service creation in the DI container. cmdguard integrates it via `WithAuditLog` with 11 export formats.

## Glamour

[Glamour](https://github.com/charmbracelet/glamour) renders markdown in the terminal. The `glamour` sub-module provides `WithHelp()` to render command help text as styled markdown.

## config explain (built in)

Not a separate library — a cmdguard feature. The opt-in `config explain` command (`WithConfigExplainCommand()`) answers "where did this value come from?" per config field (flag, env var, config file, or tag default) in table or JSON form, with `secret:"true"` values redacted.
