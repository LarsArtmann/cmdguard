## Overview

cmdguard integrates [samber/do/v2](https://github.com/samber/do) for dependency injection. Register services on the CLI scope and invoke them in handlers — no global state, no manual wiring.

## Register Services

```go
cli, _ := v4.NewCLI[AppConfig]("myapp", "...", AppConfig{})
scope := cli.Scope()

// Lazy initialization — service is created on first Invoke
v4.Provide(scope, func(i do.Injector) (*Database, error) {
    cfg, _ := v4.Invoke[*AppConfig](scope)
    return &Database{DSN: cfg.DSN}, nil
})
```

## Invoke in Handlers

```go
v4.NewCommand("query", v4.NoFlags{},
    func(ctx context.Context, cfg *AppConfig, flags v4.NoFlags) error {
        db, _ := v4.Invoke[*Database](cli.Scope())
        return db.Query(ctx)
    },
)
```

## Lifecycle Management

Services can implement health check and shutdown interfaces:

```go
type Database struct { DSN string }

// HealthCheck is called by the DoctorCommand
func (db *Database) HealthCheck() error {
    return db.Ping()
}

// Shutdown is called on SIGINT/SIGTERM (with WithGracefulShutdown)
func (db *Database) Shutdown() error {
    return db.Close()
}
```

## Signal Handling

```go
cli, _ := v4.NewCLI[AppConfig]("myapp", "...", AppConfig{},
    // Cancel context on SIGINT/SIGTERM (handlers can check ctx.Done())
    v4.WithSignalHandling(),

    // Full graceful shutdown: cancels context AND triggers DI shutdown
    // Services implementing do.ShutdownerWithError shut down in reverse order
    v4.WithGracefulShutdown(),
)
```

`WithGracefulShutdown` implies `WithSignalHandling`.

## Override for Testing

Replace services in tests without touching production code:

```go
func TestHandler(t *testing.T) {
    clone := v4.CloneScope(originalScope)
    v4.OverrideValue(clone, &Database{DSN: "test://mock"})
    // Now Invoke[*Database] returns the mock
}
```

Pattern: clone -> override -> invoke.

## NewScopeWithOpts

Create scopes with custom injector options (logging, lifecycle hooks, health check timeouts):

```go
scope := v4.NewScopeWithOpts("custom", &do.InjectorOpts{
    Logf: func(format string, args ...any) {
        log.Printf("DI: "+format, args...)
    },
})

cli, _ := v4.Package(scope, "myapp", "Description", AppConfig{})
```

## DI Logging

```go
cli, _ := v4.NewCLI[AppConfig]("myapp", "...", AppConfig{},
    v4.WithDILogging(func(format string, args ...any) {
        log.Printf("DI: "+format, args...)
    }),
)
```

## Audit Log

Wire [samber-do-auditlog](https://github.com/larsartmann/samber-do-auditlog) to trace service creation:

```go
import auditlog "github.com/larsartmann/samber-do-auditlog"

cli, _ := v4.NewCLI[AppConfig]("myapp", "...", AppConfig{},
    v4.WithAuditLog(auditlog.NewDefaultPlugin()),
)

// Access programmatically
report := cli.AuditLogReport()
failed := v4.AuditLogFailedServices(cli)
```
