## Architecture

cmdguard's core stays lean (13 direct deps). Five optional features live in standalone Go modules so you import only what you need. Each lives at the repo root for correct external resolution.

| Sub-module         | Import path                                        | Provides                       |
| ------------------ | -------------------------------------------------- | ------------------------------ |
| **glamour**        | `github.com/larsartmann/cmdguard/glamour`           | Markdown help rendering        |
| **prompts**        | `github.com/larsartmann/cmdguard/prompts`           | Interactive prompts via huh/v2 |
| **spinner**        | `github.com/larsartmann/cmdguard/spinner`           | Terminal spinner middleware    |
| **telemetry**      | `github.com/larsartmann/cmdguard/telemetry`         | OpenTelemetry spans            |
| **flightrecorder** | `github.com/larsartmann/cmdguard/flightrecorder`    | Runtime trace flight recorder  |

## Glamour — Markdown Help

Render command `Long` and `Example` text as styled markdown:

```go
import "github.com/larsartmann/cmdguard/glamour"

cli, _ := v4.NewCLI[AppConfig]("myapp", "...", AppConfig{},
    glamour.WithHelp[AppConfig](),
)
```

Uses `RenderWithEnvironmentConfig` (checks `GLAMOUR_STYLE` env var, defaults to `"dark"`).

## Prompts — Interactive Input

Enable interactive prompting for missing required flags:

```go
import "github.com/larsartmann/cmdguard/prompts"

// Register the huh/v2 prompt runner
v4.SetPromptRunner(prompts.New())

type Flags struct {
    Name string `flag:"name" prompt:"What is your name?"`
}

cli, _ := v4.NewCLI[AppConfig]("myapp", "...", AppConfig{},
    v4.WithPromptOnMissing(),
)
```

The prompt type adapts to the flag type: `bool` becomes a confirm prompt, `Enum[T]` becomes a select, everything else becomes a text input.

## Spinner — Loading Indicator

```go
import "github.com/larsartmann/cmdguard/spinner"

cli, _ := v4.NewCLI[AppConfig]("myapp", "...", AppConfig{},
    v4.WithMiddleware[AppConfig](spinner.Middleware[AppConfig]("Working...")),
)
```

## Telemetry — OpenTelemetry

```go
import "github.com/larsartmann/cmdguard/telemetry"

cli, _ := v4.NewCLI[AppConfig]("myapp", "...", AppConfig{},
    telemetry.WithTelemetry[AppConfig](tracer),
)
```

## Flight Recorder — Execution Trace Snapshots

```go
import "github.com/larsartmann/cmdguard/flightrecorder"

cli, _ := v4.NewCLI[AppConfig]("myapp", "...", AppConfig{},
    v4.WithMiddleware[AppConfig](flightrecorder.Middleware[AppConfig](
        flightrecorder.WithCaptureOnSlow(5*time.Second),
        flightrecorder.WithCaptureOnError(),
    )),
)
```

The flight recorder wraps Go 1.25+ `runtime/trace.FlightRecorder`. It continuously
buffers execution traces in memory and auto-captures snapshots when commands are slow
or error. Analyze snapshots with `go tool trace snapshot.trace`. Zero external
dependencies (stdlib only).

## Directory Layout

Each sub-module lives at the **repo root** (`<name>/`), NOT under `pkg/cmdguard/`. Go resolves module paths by finding `go.mod` at the matching directory. Moving them under `pkg/` would break external `go get` silently.
