## OutputTable

Render structured data in any of 16 formats:

```go
import "github.com/larsartmann/go-output"

headers := []string{"Name", "Status", "Created"}
rows := [][]string{"api-server", "running", "2026-01-15"}

v4.OutputTable(output.FormatTable, headers, rows)  // Aligned terminal table
v4.OutputTable(output.FormatJSON, headers, rows)    // JSON array
v4.OutputTable(output.FormatCSV, headers, rows)     // CSV
v4.OutputTable(output.FormatYAML, headers, rows)    // YAML
```

## All 16 Formats

`table`, `json`, `csv`, `tsv`, `markdown`, `xml`, `yaml`, `html`, `d2`, `tree`, `mermaid`, `dot`, `jsonl`, `asciidoc`, `toml`, `plantuml`.

## Dynamic Format via Flag

Wire the `--output` flag and let users choose:

```go
type AppConfig struct {
    Output string `flag:"output" short:"o" default:"text" help:"Output format"`
}
```

cmdguard registers the `--output` flag automatically with help text listing all available formats.

## OutputResult

For non-tabular data:

```go
v4.OutputResult(myStruct, output.FormatJSON)
```

## Shape-Aware Errors

When `--output=json` is active, errors are rendered as structured JSON instead of plain text:

```json
{
	"error": "database connection failed",
	"type": "ConnectionError",
	"exit_code": 1
}
```
