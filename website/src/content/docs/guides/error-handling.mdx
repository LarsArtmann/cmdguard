## Zero Panics

Every function in cmdguard returns errors. No `Must*` panic variants exist. This is enforced by construction — there is no `Run` field, only `RunE`.

```go
cli, err := v4.NewCLI[Config]("app", "...", Config{})
if err != nil {
    return err // never panics
}
```

## The Error-Print Contract

cmdguard owns error display so you can't get it wrong:

1. **The error is printed exactly once** — styled by [fang](https://github.com/charmbracelet/fang) when enabled (the default), or plain by Cobra when disabled.
2. **Usage is never printed on error** (`SilenceUsage: true` by default). Use `WithoutSilenceUsage()` to re-enable usage-on-error.
3. **The error returned by `Execute` is for exit-code mapping only** — do NOT re-print it.

### Recommended — one line:

```go
cli.ExecuteAndExit(context.Background())
```

### When you need code before exiting:

```go
err := cli.Execute(ctx)
// ...flush logs / export audit log / teardown...
os.Exit(v4.ExitCode(err)) // 0 on success, ExitCoder code or 1 on failure
```

### Pitfall to avoid

```go
// WRONG — re-prints the error that cmdguard already printed
if err := cli.Execute(ctx); err != nil {
    fmt.Fprintln(os.Stderr, err)
}
```

## Exit Codes

```go
// Custom exit code
err := v4.NewExitError(42, errors.New("config missing required field"))
// ExecuteAndExit will exit with code 42

// Check programmatically
code := v4.ExitCode(err) // returns 0 for nil, ExitCoder code, or 1
```

## Sentinel Errors

All errors use `fmt.Errorf("%w: ...", sentinel)` for `errors.Is()` chainability:

```go
errors.Is(err, v4.ErrInvalidCommand)
errors.Is(err, v4.ErrMissingHandler)
errors.Is(err, v4.ErrDuplicateCommand)
errors.Is(err, v4.ErrConfigValidation)
```

40+ sentinel errors cover every failure mode.

## Rich Error Types

```go
v4.NewCommandError(name, err)
v4.NewFlagError(name, err)
v4.NewFlagErrorWithSuggestion(name, err, suggestion) // includes typo fix
v4.NewExitError(code, err)                           // custom exit code
```

## Typo Suggestions

When a user mistypes a flag or command, cmdguard suggests the closest match:

```bash
$ myapp greet --nmae "World"
Error: unknown flag: --nmae
Did you mean: --name?
```

## Error Aggregation

Config validation uses `errors.Join` so individual errors are reachable:

```go
errs := v4.ValidateConfig(cfg)
for _, err := range errs {
    if errors.Is(err, v4.ErrConfigValidation) {
        // handle
    }
}
```
