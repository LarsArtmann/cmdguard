Every symbol below exists in `github.com/larsartmann/cmdguard/v5/pkg/cmdguard/v5`.
The package is conventionally imported without an alias, so examples call
`v5.NewCLI` after importing the package as `v5`.

## Core types

| Type | Meaning |
| --- | --- |
| `CLI[T]` | The root CLI. `T` is the root config struct; its tagged fields become the root flags. |
| `Command[T, F]` | One command. `F` is that command's own flag struct, passed by value to the handler. |
| `NoFlags` | The explicit "this command has no flags of its own" type. It is a named type, not an alias. |
| `Builder[T]` | Collects constructor errors and attaches commands atomically. |
| `Scope` | The DI scope, wrapping `samber/do/v2`. |
| `OutputFormat` | Alias of `go-output`'s `Format`. |

Handlers have the signature `func(ctx context.Context, cfg *T, flags F) error`.
Positional arguments are read with `ArgsFromContext(ctx)`.

## Constructors

| Function | Returns |
| --- | --- |
| `NewCLI[T](name, short string, defaults T, opts ...CLIOption)` | `(*CLI[T], error)` |
| `NewApp[T](name, short string, defaults T, build func(*CLI[T]) error, opts ...CLIOption)` | `(*CLI[T], error)` |
| `NewCommand[T, F](use string, flags F, runE func(context.Context, *T, F) error, opts ...CommandOption)` | `(Command[T, F], error)` |
| `NewParentCommand[T, F](use, long string, flags F, opts ...CommandOption)` | `(Command[T, F], error)` |
| `NewBuilder[T](cli *CLI[T])` | `*Builder[T]` |
| `AddCommand[T, F](cli *CLI[T], cmd Command[T, F])` | `error` |
| `AddCommands[T](cli *CLI[T], cmds ...AddableCommand[T])` | `error` |

Commands are returned by value, not by pointer. Flags are passed by value too:
`NewCommand("scan", ScanFlags{}, handler)`.

## Registration

```go
b := v5.NewBuilder(cli)
v5.Add(b, listCmd)       // queue an already-built command
v5.AddParent(b, dbCmd)
v5.Try(b, queryCmd, err) // queue a (value, error) pair
b.Check(anotherErr)      // fold in any other error
if err := b.Build(); err != nil {
	return err
}
```

`Build()` attaches all queued commands or none, and reports the first error.
Duplicate detection keys on the cobra command name.

## CLI methods

### Execution

| Method | Purpose |
| --- | --- |
| `Execute(ctx) error` | Run the CLI |
| `ExecuteWithArgs(ctx, args) error` | Run with explicit arguments; safe to call repeatedly |
| `ExecuteAndExit(ctx)` | Run and exit with the mapped code |
| `Shutdown(ctx) error` | Tear down the DI scope explicitly |

### Introspection

| Method | Purpose |
| --- | --- |
| `Describe() *CLIDescription` | Machine-readable contract |
| `WriteDescription(w) error` | Write the contract as JSON |
| `GenerateDocs(w) error` | Write Markdown documentation for the tree |
| `ExplainConfig() ConfigExplanation` | Where each config value came from |
| `ConfigDiagnostics() []ConfigDiagnostic` | Config problems for `doctor` |
| `ConfigFilePath() string` | The config file that was loaded |
| `StrictConfigKeys() bool` | Whether unknown keys are rejected |

### Configuration and output

| Method | Purpose |
| --- | --- |
| `Config() *T` | The resolved config |
| `Name()`, `Short()`, `Long()` | Identity strings |
| `SetLong(long)`, `SetVersion(version)` | Mutate identity |
| `OutputFormat()`, `SetOutputFormat(f)` | Read or set the output format |
| `NoColor() bool` | Whether color output is disabled |

### DI and health

| Method | Purpose |
| --- | --- |
| `Scope() *Scope` | The DI scope |
| `Injector() do.Injector` | The underlying injector |
| `HealthCheck(ctx) error` | First failing health check |
| `HealthCheckResults() map[string]error` | All service results |
| `HealthCheckResultsWithContext(ctx) map[string]error` | All results, context-aware |
| `RecordAuditHealthCheck(ctx) map[string]error` | Results, also recorded in the audit log |

### Audit and escape hatches

| Method | Purpose |
| --- | --- |
| `AuditLog() *auditlog.Plugin` | The audit plugin, when enabled |
| `AuditLogReport() *auditlog.Report` | A report snapshot |
| `RootCommand() *cobra.Command` | The underlying cobra tree |
| `FlowContext() *BranchingFlowContext` | The execution flow tree |
| `RegisterLocalCommandFlags(cmd) error` | Opt a subcommand into root-local flags |
| `AddGlobalFlag`, `AddGlobalBoolFlag` | Register untagged flags |

## Value types

`Duration`, `Port`, `Email`, `URL`, `HostPort`, `FilePath`, `Enum`, `LogLevel`,
`LogFormat`, each with a `Parse*` constructor. `time.Duration` and `time.Time`
are supported directly. These types stay atomic when nested in a config struct;
other nested structs are flattened into flags.

## Error types

| Type | Constructor |
| --- | --- |
| `CommandError` | `NewCommandError(name, err)` |
| `FlagError` | `NewFlagError(name, err)`, `NewFlagErrorWithSuggestion(name, err, suggestion)` |
| `ConfigError` | `NewConfigError(field, err)` |
| `EnumError` | `NewEnumError(value, allowed)` |
| `DurationError` | `NewDurationError(value, err)` |
| `ServiceError` | `NewServiceError(serviceType, err)` |
| `ExitError` | `NewExitError(code, err)` |

All sentinels are wrapped with `fmt.Errorf("%w: ...", sentinel)` and reachable
with `errors.Is`; typed errors are reachable with `errors.AsType[*T]` (Go 1.26+).
The complete catalog, generated from the same table the runtime uses, lives in
the repository's `docs/ERROR_REFERENCE.md`.
