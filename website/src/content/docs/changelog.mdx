## v4.0.0 — 2026-07-28

### Breaking Changes

- **Module path:** `github.com/larsartmann/cmdguard/v3` → `github.com/larsartmann/cmdguard/v4`
- **Package directory:** `pkg/cmdguard/v3/` → `pkg/cmdguard/v4/`
- **Config loading:** `configload` sub-package deleted; `WithConfigFile(paths...)` now auto-detects JSON/YAML/TOML via `KoanfLoader`
- `NewJSONLoader` deleted

### Changed

- go-output upgraded v0.31.1 → v0.35.0
- samber-do-auditlog upgraded v0.7.0 → v0.8.1
- 500 test functions, 29 benchmarks, 8 fuzz targets, 87.8% coverage, 0 lint issues

### Sub-Modules

5 optional sub-modules (each independently importable):
`glamour`, `prompts`, `spinner`, `telemetry`, `flightrecorder`.

### v2 Maintenance

The v2 line continues at `v2.10.4`. See the [v2 to v3 Migration Guide](https://github.com/larsartmann/cmdguard/blob/main/docs/MIGRATION_v2_v3.md).
